## 主要功能

按需配置并启用插件和扩展服务。

| 类别 | 功能与用途 |
|---|---|
| 上网与无线 | WAN/LAN、双频 Wi-Fi、MediaTek HNAT 硬件加速、全锥形 NAT、UPnP |
| DNS 解析 | 自动或手动指定上游 DNS，可选 DoH 加密查询及故障时的普通 DNS 回退；见[设置方法](#dns-over-https) |
| 设备管理 | DHCP 静态租约、ARP 绑定、上网时段控制、设备限速、DDNS |
| 状态与统计 | CPU、内存与温度概览，双频信道分析、流量统计和系统监控 |
| 日常维护 | 网页文件传输、SSH/SFTP、时间同步、定时重启、网页终端 |

Argon 3.0.0 默认使用居中登录卡片，也可在主题设置中切换为经典布局；已有的布局选择会保留。

手动上传 APK 时，可选择仅对本次安装生效的签名验证和联网下载选项，操作方法见[软件包安装](../flashing.md#package-install)。

## 首次使用

1. 有线接入 LAN，在浏览器打开 `192.168.31.1`，以 `root` 登录并设置管理密码；首次启动未预设密码。
2. 设置 WAN 上网方式、Wi-Fi 名称与密码。默认主机名为 `Redmi_AX6000`，时区为 `Asia/Singapore`（UTC+8），LAN IPv6 默认关闭。需要更改 DNS 时，按[PPPoE / DHCP 的设置步骤](../features/dns.md#ordinary-dns)操作，并检查 IPv6 接口；需要加密查询时，继续设置下方的[DoH](#dns-over-https)。
3. 在“网络 → DHCP”中管理静态租约、分配固定地址，离线设备的记录也会保留。ARP 绑定只固定 IP 与 MAC 的邻居映射，不负责给设备分配地址。
4. 使用网页文件传输或 SFTP 上传、下载文件。SFTP 与 SSH 使用相同的端口和登录认证，默认端口为 `22`；修改 SSH 端口后，SFTP 也使用该端口。
5. 基础上网正常后再配置扩展服务。OpenClash 需要下载代理核心、导入自己的配置并启用。

上述为出厂默认设置。保留配置升级时，继续使用原有配置。

地址分配、固定 IP 与 ARP 绑定见[LAN 与地址分配](../features/lan.md)；普通 DNS 的来源与设置见[DNS 工作原理与配置](../features/dns.md#ordinary-dns)。

使用 SSH/SFTP 时，可通过 `/root/tmp` 访问临时目录 `/tmp`，通过 `/root/opt` 访问 `/opt`。`/tmp` 使用内存，重启后内容会清空。

<a id="dns-over-https"></a>

### 配置加密 DNS（DoH）

在 **网络 → DNS → 加密 DNS** 中开启 DoH，可以加密路由器向 DoH 上游发送的域名查询。默认关闭；WAN 使用 DHCP 或 PPPoE 均可启用。

URL、引导 IP、故障回退的用途与设置步骤见[加密 DNS 教程](../features/dns.md#doh)；查看上游来源和解析状态见[读懂当前上游](../features/dns.md#status)。

| APK 安装结果 | 分别提示安装成功、失败或无法确认；连接中断时提醒先检查已安装列表，再决定是否重试。 |
| 上传包临时存放 | 每次上传单独保存在内存临时目录，取消或安装结束后清理，避免多个页面相互覆盖上传包。 |
| OpenClash 备份占用 | 创建备份时跳过与固件内置文件一致、且未修改权限或归属的指定数据库，保留用户修改和配置；首次从旧版本升级的处理见[备份空间说明](../flashing.md#backup-space)。 |

## 更新与回退

| 使用场景 | 文件与操作 |
|---|---|
| 系统内更新 | 在“系统 → 备份/升级”上传普通 110m 的 `*squashfs-sysupgrade.bin`。同系列且配置兼容时可保留设置，回退旧版建议清空。 |
| 跨系列切换 | 升级或回退都取消保留配置，重新设置网络和安装兼容插件，不整包恢复另一系列的备份。 |
| U-Boot 安装或恢复 | 使用同包 `*squashfs-factory.bin`；多布局引导选择 `immortalwrt-110m`，不要选择 `default`。 |
| 首次安装或更新引导 | 使用 RB06 普通 110m 配套 `bootloader/mt7986_redmi_ax6000-fip-fixed-parts.bin`，并按该发行文件清单确认附件。日常系统更新无需重刷 FIP。 |

三套固件均附带普通 110m 的引导文件，无需先安装 21.02。FIP 负责启动，factory/sysupgrade 镜像用于安装系统。原厂设备先解锁、备份本机分区，再按[首次安装步骤](../flashing.md#原厂首次安装)准备引导；不要将 FIP 上传到 LuCI 系统升级页面。

镜像检查不通过时，先核对设备、文件和布局，再按[旧版处理与恢复步骤](../flashing.md#配置与插件怎么恢复)处理；不要勾选强制升级。

升级前备份配置、上网参数和插件数据。升级后重新安装外装插件，完整流程见[安装、升级与恢复](../flashing.md)。

## 使用须知

- 第三方插件请选择适配 FW4 / nftables 的 APK 版本；IPK 安装包不能用于本系列。
- 内核模块须匹配本固件的内核版本与 ABI。无线驱动和芯片固件随完整系统一起更新，请勿混装其他系统的版本。
- 同时启用硬件加速、透明代理或软件限速后，检查实际访问和限速效果；加速流量可能无法完整计入统计。
- 在“快速转发引擎”选择 MediaTek HNAT，并勾选硬件加速，才会启用这条加速路径；IPv6 加速选项只控制 IPv6 硬件转发。保存后查看上方运行状态，确认设置是否生效。
- 透明代理接管的流量不一定受上网时段控制。需要按时段完整断网时，先停用相关透明代理，再检查实际效果。
- 信道分析用于查看周边无线网络。需要调整工作信道时进入无线设置；扫描会短暂占用无线资源。

反馈时请提供固件完整版本、安装方式和复现步骤，见[反馈说明](../../README.md#反馈)。
