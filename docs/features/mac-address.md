# MAC 地址：查看、修改与恢复

[返回首页](../../README.md) · [功能指南](README.md) · [25.12 系统说明](../systems/25.12-6.12.md) · [LAN 与地址分配](lan.md)

在 **网络 → MAC 地址** 中，可以集中查看和设置路由器的 WAN、LAN 整体、2.4 GHz 和 5 GHz 地址。每个接口都可选择原厂地址、按厂商生成或手动填写，核对后通过重启应用。

<a id="availability"></a>

**适用于提供“网络 → MAC 地址”页面的 25.12 固件。** 21.02、24.10 使用各自原有的接口设置。2026-11-09 发布的 25.12 固件 `r0-41187c9` 尚未包含此管理页面；升级前请在[发行说明](https://github.com/SundayRX/ImmortalWrt_Firmware_Redmi_AX6000/releases?q=%2225.12-6.12%22)及包内 `packages.txt` 中确认版本包含 `luci-app-mac-manager`。

<a id="interfaces"></a>

## 先确认要修改哪个接口

MAC 地址用于识别网络接口。需要调整上级网络识别到的 WAN 地址、设置路由器的有线或无线接口地址，或恢复原厂地址时，可在本页操作。

| 接口 | 管理的地址 |
|---|---|
| **WAN** | 路由器外网接口的地址，光猫、上级路由器或接入网络会使用它识别连接的接口 |
| **LAN 整体** | 路由器 LAN 网桥与有线 LAN 网口统一使用的地址 |
| **2.4 GHz** | 该频段主要 Wi-Fi 网络的地址，可通过行内显示的 SSID 辨认 |
| **5 GHz** | 该频段主要 Wi-Fi 网络的地址，可通过行内显示的 SSID 辨认 |

页面修改的是路由器接口地址。电脑、手机等终端仍使用各自网卡的 MAC；为终端分配固定 IP，请使用[静态租约](lan.md#fixed-address)。有附加 Wi-Fi 网络时，请先核对页面显示的 SSID，其他网络继续在无线设置中管理。

左侧显示 **当前生效 MAC**，右侧 **待设置 MAC** 是正在编辑的候选地址。关闭某个无线频段后，左侧改为显示其已保存地址，并标注 **无线已禁用**；仍可查看和修改，保存地址不会开启该频段。

<a id="modes"></a>

## 选择地址设置方式

| 设置方式 | 用途与操作 |
|---|---|
| **原厂 MAC** | 使用由设备出厂数据确定的接口地址。选择后，右侧显示将恢复的地址 |
| **厂商生成** | 按所选厂商的地址段生成地址，前缀与后缀可分开调整 |
| **手动填写** | 输入需要使用的完整 MAC 地址，适合已有明确地址要求的情况 |

WAN、LAN 的原厂地址来自设备保存的出厂信息；无线地址由出厂无线数据与对应接口的分配规则确定。2.4 GHz 和 5 GHz 分别使用各自的地址，开头可能不同。

自定义地址保存在系统配置中，设备的出厂数据保留。以后可以再次选择 **原厂 MAC**，按[恢复步骤](#restore)应用。

手动地址由六组十六进制数字组成，以冒号分隔。各行的自定义地址请避免相互重复，也不要与局域网其他设备使用相同地址；页面会检查地址格式和本机可识别的接口冲突。若上级网络要求固定 WAN 地址，请按该网络允许的地址填写。

<a id="generate"></a>

## 按厂商生成地址

在 **生成地址的厂商** 中按厂商名称或 MAC 前缀搜索并选择。列表左侧的 **⭐** 标记有家用 Wi-Fi 产品的厂商，历史产品另有说明。一个厂商可能登记多个地址段，随机生成会从可用段中选择。标为 **仅查询** 的条目用于查看登记信息，生成时请选择有可用地址段的厂商。

选择厂商后，用下面的按钮调整地址：

| 操作 | 作用 |
|---|---|
| **随机厂商前缀** | 为勾选的接口选用同一个厂商地址段，保留各地址在该前缀以外的部分 |
| **随机后缀** | 保留各行当前地址的厂商前缀，分别重新生成后面的部分 |
| 输入框旁的随机按钮 | 仅随机这一行的后缀，保留该地址的厂商前缀 |

厂商地址段的长度可能不同，后缀随机会保留对应地址段的完整前缀。

如果希望 WAN、LAN 和两个 Wi-Fi 使用相同厂商前缀、各自不同的后缀：

1. 选择厂商，勾选需要修改的接口。
2. 将这些行的设置方式选为 **厂商生成**。
3. 点击 **随机厂商前缀**，统一所选行的前缀。
4. 点击 **随机后缀**，为各行生成不同的地址，并检查右侧结果。
5. 按[保存并重启](#apply)的步骤应用。

顶部切换厂商只改变选择；把某一行切换为 **厂商生成** 时，会为该行生成厂商前缀并保留后缀。顶部两个随机按钮会保留 **手动填写** 和未勾选的行。

**勾选框只控制批量随机操作。保存会处理页面中所有已修改的行。** 前缀调整后若提示地址重复，可以随机后缀或手动修正，再保存。

<a id="apply"></a>

## 核对地址后保存并重启

```mermaid
flowchart LR
    A[选择接口与地址] --> B[保存并重启]
    B --> C[核对变化并确认]
    C --> D[保存设置并重启路由器]
    D --> E[重新进入页面核对地址]
```

1. 检查每一行的 **待设置 MAC**，确认需要保留和修改的接口。
2. 点击 **保存并重启**，在确认框中核对修改前后的地址。需要继续调整时取消确认，返回编辑。
3. 点击 **确认并重启**。页面依次提示 **正在保存设置…**、**正在重启…**。保持路由器供电，待重启完成后按下一步重新打开管理页面。
4. 路由器重启后，重新连接网络，使用原管理地址登录，再进入 **网络 → MAC 地址** 核对当前生效值。

新地址在重启后使用。重启期间，有线连接、Wi-Fi 和上网连接会暂时断开；WAN 地址变化后，上级网络可能重新分配地址或要求更新绑定。被禁用的无线频段继续显示已保存地址，启用后再核对实际地址。

<a id="restore"></a>

## 恢复原厂地址或上次设置

| 想完成什么 | 操作方法 |
|---|---|
| 放弃这次尚未保存的编辑 | 点击 **撤销修改**，恢复为页面读取到的已保存设置 |
| 恢复某个接口的原厂地址 | 将该行选为 **原厂 MAC**，核对右侧地址，再保存并重启 |
| 恢复所有接口的原厂地址 | 将四行分别选为 **原厂 MAC**，统一核对后保存并重启 |
| 恢复最近一次保存之前的设置 | 点击 **恢复上次保存前设置**，核对恢复内容，再确认保存并重启 |

“恢复上次保存前设置”提供最近一次保存的恢复记录；没有可用记录时，按钮不可用。恢复过程中取消确认，会返回恢复操作前的编辑内容。

<a id="persistence"></a>

## 重启、升级和重新安装后会怎样

地址在生成并保存后固定使用，重启时继续使用已保存值。

| 操作 | 自定义 MAC 的处理 |
|---|---|
| 日常重启或断电后开机 | 保留已保存设置 |
| 同一系列且配置兼容，选择保留配置升级 | 设置随配置保留；目标固件需支持此管理功能 |
| 取消保留配置升级或恢复出厂设置 | 按系统默认配置启动，需要重新设置自定义地址 |
| 通过 U-Boot 网页刷写 factory 系统镜像 | 按重新安装处理，需要重新设置自定义地址 |
| 在 25.12、24.10、21.02 之间切换 | 按[跨系列升级说明](../flashing.md)取消保留配置，安装后重新配置 |

升级前按[备份与升级说明](../flashing.md)保存配置备份。

<a id="troubleshooting"></a>

## 常见问题

| 现象 | 处理方法 |
|---|---|
| 菜单中没有“MAC 地址” | 核对固件是否包含此管理功能，见[适用范围](#availability) |
| 无线已禁用，左侧仍有 MAC | 左侧显示已保存地址，可继续编辑；启用无线后再查看实际地址 |
| 点击批量随机后，部分行没有变化 | 检查是否勾选，以及该行是否为 **手动填写** |
| 随机后缀提示无法识别前缀 | 先选择厂商并使用 **随机厂商前缀**，再随机后缀 |
| 提示地址重复或格式无效 | 修改提示对应的行，消除冲突后再保存 |
| 原厂地址暂不可用，或接口无法编辑 | 刷新页面查看提示；如调整过 VLAN、网桥或网口分配，先核对当前接口设置 |
| 提示其他页面有未保存的网络修改 | 先处理其他页面的修改，再重新打开本页核对地址 |
| 重启后暂时无法进入管理页面 | 等待路由器完成启动，重新连接有线或 Wi-Fi，再用管理地址登录 |
| 修改 WAN 地址后无法上网 | 检查上级网络的地址绑定要求；需要恢复时，将 WAN 选为 **原厂 MAC** 或恢复上次保存前设置，再保存并重启 |
